# Dev Dash

A web-based typing game designed to challenge players to type quickly and accurately.

## 🎮 About the Project

**Dev Dash** is a browser-based typing game where players compete against the clock by typing the displayed text as quickly and accurately as possible.

The game is designed to make typing practice more engaging by combining:

* ⚡ Fast-paced typing challenges
* 🎯 Accuracy-based scoring
* ⏱️ Time pressure
* 🏆 Performance tracking
* 🎮 Interactive gameplay
* 💻 A lightweight web-based experience

The project was created as a personal development project to practice web development while creating an interactive game that can be played directly in a browser.

## ✨ Features

* **Typing Challenge**
  Players must type the displayed text as quickly and accurately as possible.

* **Speed Tracking**
  The game measures the player's typing performance.

* **Accuracy Tracking**
  Incorrect characters affect the player's accuracy.

* **Score System**
  Player performance is converted into a score based on typing speed and accuracy.

* **Interactive Gameplay**
  The interface responds to the player's typing in real time.

* **Browser-Based**
  No installation is required. The game can run directly in a modern web browser.

## 🕹️ How to Play

1. Start the game.
2. Read the text displayed on the screen.
3. Type the text as quickly and accurately as possible.
4. Avoid making mistakes.
5. Complete the challenge before the timer runs out.
6. Check your final score and typing performance.
